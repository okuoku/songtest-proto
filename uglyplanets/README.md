みにくい星(Uglyplanets)
=====================

サビの最初の1行だけ自分のゲームシナリオから持ってきて残りは即興。直接ComfyUIのノードエディタで書いた。
最初のテストなので自分の作風に忠実な曲。

歌詞(調整前)
-----------

```
いつもの世界で目覚めてもつめたい窓に景色は無くて
僕の手からこぼれる君を忘れられずに目を閉じる
重い重い扉を開けて今日の空気に触れながら
大丈夫って君の言葉を自分の声で言ってみる

ピカピカでキラキラの空へ旅をするの
道を忘れた君の思い出と手をつないで
虹の下で僕はきっとひとりだけど
最後の歌をこの星は忘れないんだ

少しあぶないおしゃれでも今日なら好きになれちゃうのかな
笑顔の自分なんてとても見つけられないはずなのに
みにくい星でもひとつだけ輝くものがあるのなら
僕にはそれが感じられるのこの星と一つになって

大好きなこの町はいつも夢の終り
誰も知らない輝く町は僕らの秘密
朝がこない星でそっと息をすって
僕の記憶を歌にして届けたいんだ

こぼれていく僕の心
暗闇の空もさかさま
流れていく星の命
昨日を知らない旅立ち
```
